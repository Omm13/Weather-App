# Weather App

A responsive weather application built using HTML, CSS, and JavaScript. The app retrieves real-time weather information from a weather API and displays current weather conditions, temperature, and location details based on user searches.

This project was developed as part of my Web Development Internship at Prodigy InfoTech and focuses on API integration, asynchronous JavaScript, and responsive frontend development.

## Overview

The Weather App allows users to search for any city and instantly view its current weather information. The application communicates with a weather API, processes the received data, and presents it in a clean and user-friendly interface.

## Features

* Search weather by city name
* Real-time weather data retrieval
* Current temperature display
* Weather condition information
* Location details
* Responsive design
* Fast and lightweight interface
* API integration using JavaScript

## Technologies Used

* HTML5
* CSS3

## How It Works

1. User enters a city name.
2. The application sends a request to the weather API.
3. Weather data is retrieved asynchronously.
4. Relevant information is extracted and displayed.
5. Users can search multiple cities without refreshing the page.
